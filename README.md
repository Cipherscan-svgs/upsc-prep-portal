# CivilQuest - UPSC Prep Portal

A comprehensive web application designed to help aspirants prepare for the UPSC Civil Services Examination.

## Features
* **NCERT Library:** Access digital books from Class 6 to 12 (History, Geography, Polity, etc.).
* **Standard Reference Books:** Chapter-wise notes and summaries.
* **UPSC PYQ Vault:** Past 10 years of question papers for both Prelims and Mains.
* **Practice Bits:** Chapter-wise MCQ quizzes mapped to specific books to test your knowledge.

## Tech Stack
* React
* Tailwind CSS
